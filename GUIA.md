# Guia rápido

Tudo o que você precisa saber está no [README](README.md).

Resumo do dia a dia:

- **Chegou issue com o nome de uma empresa e um período** (ex.: "Bluefit — Demonstrações financeiras trimestrais (ITR) — 3º trimestre de 2026"):
  é um documento novo. O link do PDF está dentro da issue.
- **Chegou issue "⚠️ ... sem monitoramento":** o robô não está conseguindo ler aquela
  empresa. Confira o site dela manualmente até a issue ser encerrada sozinha.
- **Chegou issue "Linha de base registrada — ...":** o robô leu a empresa pela primeira
  vez. Abra o site e confira se o documento mais recente listado é mesmo o último.
- **Quer testar sem risco:** Actions → "IR Watch (inspect validation)" → Run workflow.
